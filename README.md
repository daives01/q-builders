# Q Builders Colorado

Static marketing site for Q Builders, a custom home builder in Denver, Colorado.

**Live:** [qbuilderscolorado.com](https://qbuilderscolorado.com)

## Tech Stack

- [Astro](https://astro.build) — Static site generation
- [Tailwind CSS](https://tailwindcss.com) — Styling
- [Cloudflare Pages](https://pages.cloudflare.com) — Hosting

## Development

```sh
bun install
bun run dev
```
